Test Qdrant MCP tools in Codex:

1. Run: cxe
2. Once Codex opens, try these commands:

Store information:
@qdrant_project.qdrant-store "NoteChat uses SwiftUI for UI and SwiftData for persistence"

Find information:
@qdrant_project.qdrant-find "SwiftUI"

Alternative (if the above doesn't work, try without the server prefix):
@qdrant-store "Test information"
@qdrant-find "Test"

If you get "Unknown tool" errors, the MCP server isn't being recognized.
If you get other errors about collections or connections, the server is working but may need initialization.
